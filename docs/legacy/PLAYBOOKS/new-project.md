# Playbook: New Project

1. Run `project_initiator`.
2. Create a project brief from `templates/PROJECT_BRIEF.md`.
3. Run `product_planner`.
4. Run `technical_planner`.
5. Ask `orchestrator` to split the first milestone into agent tasks.
6. Run `qa`, `security`, and `reviewer` before release.
7. Capture environment improvements.
